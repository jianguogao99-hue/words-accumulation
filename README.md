# Words accumulation

Personal IELTS wordbook. This repository is the sole source of truth.

## Deployment

Connect main to the existing Netlify project jianguo-wordslist-129830. Publish directory: dist. Build command: empty (static HTML/JS).

## Updates

Explain words in chat first; save only when requested. Read the latest main branch, update dist/data.js and UK/US audio, preserve the UI, commit, then verify Netlify deployment success. Learning progress is local to each browser.

## Personal ordering

Select **Reorder**, then drag the right-hand handles and select **Done**. Changes are saved on this browser/device; they do not rearrange other visitors’ lists. Keyboard users can focus a handle and press Up/Down. Filtering keeps hidden words in their current slots. Exported words follow the chosen order. New published words appear after the saved ordering.
